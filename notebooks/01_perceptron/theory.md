# 模块 01：感知器（Perceptron）

## 核心概念

感知器是最简单的神经网络单元，由 Frank Rosenblatt 于 1958 年提出。
它模拟单个神经元的行为：接收多个输入，加权求和后，通过阶跃函数决定是否"激活"。

## 实际作用（用途）

- 作为神经网络的最小构件，帮助理解“加权求和 + 激活函数 + 参数更新”的基本范式。
- 可用于线性可分的二分类任务，例如简单垃圾邮件过滤、规则清晰的质量检测或基础风险判定。
- 是理解更复杂模型（Logistic Regression、MLP、CNN、Transformer）的起点：后续模型本质上都是在扩展特征表达、非线性能力和训练方式。

## 代码思路

本章代码按“定义模型 -> 训练 -> 验证 -> 可视化”的顺序组织：

1. 先用 `Perceptron` 类保存权重 `w`、偏置 `b`、学习率和训练轮数，让模型状态集中在一个对象里。
2. `predict` 负责前向计算：先算线性得分 `X @ w + b`，再用阶跃函数把得分转成 0/1 类别。
3. `fit` 逐个样本训练：如果预测错了，就用 `target - pred` 得到更新方向，并同时更新权重和偏置。
4. 用 AND 逻辑门作为最小线性可分数据集，便于直观看到感知器是否能收敛。
5. 最后画出二维决策边界，把抽象的 `w` 和 `b` 转成平面上的分类直线。

## 数学定义

给定输入向量 **x** ∈ ℝⁿ 和权重向量 **w** ∈ ℝⁿ，感知器的输出为：

```
ŷ = step(w · x + b)

其中 step(z) = 1 if z ≥ 0 else 0
```

## 学习规则

感知器更新规则（Perceptron Learning Rule）：

```
w ← w + η · (y - ŷ) · x
b ← b + η · (y - ŷ)
```

其中 η 为学习率，y 为真实标签，ŷ 为预测输出。

## 局限性

感知器只能学习**线性可分**的数据。
对于 XOR 这类非线性问题，单层感知器无法收敛。
