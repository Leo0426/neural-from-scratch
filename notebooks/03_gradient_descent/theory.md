# 模块 03：梯度下降（Gradient Descent）

## 核心概念

梯度下降是通过沿损失函数梯度的反方向迭代更新参数来最小化损失的优化算法。

## 实际作用（用途）

- 是训练神经网络、线性模型、推荐模型和大语言模型的核心优化方法。
- 当参数量很大、无法直接求解析解时，通过小步迭代把模型逐渐调到更低损失的位置。
- Mini-batch GD 让模型可以在大规模数据上训练，是现代深度学习框架默认的训练方式。
- Adam、Momentum 等优化器用于提升收敛速度和稳定性，减少学习率选择不当带来的训练问题。

## 代码思路

本章代码把优化器放在同一个损失面上比较：

1. `loss(theta)` 构造一个二维损失函数，二次项形成整体下降方向，三角项制造局部起伏。
2. `grad(theta)` 手写解析梯度，让每个优化器都基于同一组梯度更新参数。
3. `optimize` 接收优化器名称，根据 `sgd`、`momentum`、`adam` 选择不同更新公式。
4. 每次更新后把当前参数保存到 `path`，后续可以画出优化轨迹，而不只是看最终结果。
5. 验证部分用有限差分和 PyTorch autograd 检查手写梯度，避免优化结果建立在错误梯度上。

## 基本更新规则

```
θ ← θ - η · ∇L(θ)
```

其中 η 为学习率，∇L(θ) 为损失对参数的梯度。

## 三种变体

| 变体 | 每步使用数据量 | 特点 |
|------|--------------|------|
| Batch GD | 全部数据 | 稳定，但每步慢 |
| SGD | 单个样本 | 快，但噪声大 |
| Mini-batch GD | 一批样本 | 折中方案，实践最常用 |

## 动量（Momentum）

引入速度变量，积累历史梯度方向：

```
v ← βv - η · ∇L(θ)
θ ← θ + v
```

## Adam 优化器

结合动量与自适应学习率（Kingma & Ba, 2014）：

```
m ← β₁m + (1-β₁)∇L      # 一阶矩
v ← β₂v + (1-β₂)(∇L)²   # 二阶矩
m̂ = m / (1-β₁ᵗ)          # 偏差修正
v̂ = v / (1-β₂ᵗ)
θ ← θ - η · m̂ / (√v̂ + ε)
```

- Kingma, D. P., & Ba, J. (2014). *Adam: A Method for Stochastic Optimization.*
