# 模块 07：卷积神经网络（CNN）

## 核心概念

CNN 通过卷积操作自动提取图像的局部特征，利用权重共享大幅减少参数量。

## 实际作用（用途）

- 广泛用于图像分类、目标检测、医学影像分析、OCR、工业缺陷检测和自动驾驶感知。
- 卷积核能学习局部模式，例如边缘、纹理、角点、零件形状，再逐层组合成更高层语义。
- 权重共享让模型在不同位置识别同一种模式，适合处理具有空间结构的数据。
- 许多现代视觉模型仍保留 CNN 思想，例如局部感受野、下采样、多尺度特征和残差连接。

## 代码思路

本章代码用最小图像例子拆解卷积和池化：

1. `conv2d_single` 先处理 padding，再按 stride 滑动卷积核，对每个局部窗口做逐元素乘积求和。
2. `maxpool2d` 用同样的滑动窗口思想，只是每个窗口保留最大值，用于降采样和保留强响应。
3. 人工构造一个 8x8 竖条图像，让边缘检测卷积核的效果更容易观察。
4. 卷积后接 ReLU 去掉负响应，再做 MaxPool 得到更小的特征图。
5. 验证部分用 PyTorch `conv2d` 对照手写卷积，确认窗口索引、padding 和输出形状正确。

## 卷积操作

给定输入特征图 X 和卷积核 K，输出特征图：

```
(X * K)[i, j] = Σₘ Σₙ X[i+m, j+n] · K[m, n]
```

- **stride**：卷积核的移动步长
- **padding**：在输入边缘填充零，控制输出尺寸

## 关键组件

| 组件 | 作用 |
|------|------|
| 卷积层 | 提取局部特征 |
| 激活层（ReLU） | 引入非线性 |
| 池化层（MaxPool） | 降采样，增强平移不变性 |
| 全连接层 | 分类决策 |

## LeNet-5 结构

```
Conv(6, 5×5) → AvgPool → Conv(16, 5×5) → AvgPool → FC(120) → FC(84) → FC(10)
```

## ResNet 残差连接

```
H(x) = F(x) + x
```

残差连接允许梯度直接跳过若干层，有效训练极深网络（100+ 层）。
