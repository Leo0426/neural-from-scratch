# 模块 04：反向传播（Backpropagation）

## 核心概念

反向传播是一种高效计算神经网络中所有参数梯度的算法。
其本质是**链式法则**在计算图上的系统性应用。

## 实际作用（用途）

- 让深层神经网络能够自动知道“每个参数该往哪个方向改”，是模型训练的基础机制。
- 支撑图像识别、语音识别、机器翻译、推荐系统和 LLM 等几乎所有深度学习应用。
- 自动微分框架（PyTorch、TensorFlow、MLX、JAX）本质上都在用计算图和链式法则实现反向传播。
- 帮助定位训练问题：梯度为 0、梯度爆炸或某层梯度异常时，可以判断模型是否学不到有效表示。

## 代码思路

本章代码把两层网络拆成前向和反向两部分：

1. 先构造小批量输入、目标值和两层网络参数，使所有矩阵形状都足够小，方便手算和检查。
2. `forward` 计算 `z1 -> a1 -> z2`，并把中间变量放进 `cache`，因为反向传播需要复用这些值。
3. `mse_loss` 只负责计算损失，保持损失函数和梯度计算逻辑分离。
4. `backward` 从输出层误差 `dz2` 开始，按链式法则依次求 `W2/b2`、隐藏层误差、`W1/b1` 的梯度。
5. 验证部分用 PyTorch autograd 对照每个参数梯度，确认手写反向传播的公式和形状都正确。

## 链式法则

对于复合函数 L = f(g(x))：

```
dL/dx = dL/df · df/dx
```

在神经网络中，梯度从输出层逐层向输入层传递（"反向"传播）。

## 前向传播

```
z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
a⁽ˡ⁾ = σ(z⁽ˡ⁾)
```

## 反向传播

输出层误差：`δ⁽ᴸ⁾ = ∇ₐL ⊙ σ'(z⁽ᴸ⁾)`

隐藏层误差：`δ⁽ˡ⁾ = ((W⁽ˡ⁺¹⁾)ᵀ δ⁽ˡ⁺¹⁾) ⊙ σ'(z⁽ˡ⁾)`

参数梯度：
```
∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ (a⁽ˡ⁻¹⁾)ᵀ
∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾
```
