# 模块 02：线性回归（Linear Regression）

## 核心概念

线性回归试图找到一条直线（或超平面），使预测值与真实值之间的误差最小化。
这是理解梯度下降最直观的切入点。

## 实际作用（用途）

- 用于预测连续数值，例如房价、销售额、广告转化、能耗、温度或库存需求。
- 常作为业务建模的强基线：当线性回归已经足够好时，复杂模型不一定值得引入。
- 帮助解释特征与目标之间的方向和强度，例如判断“面积增加是否通常带来房价上涨”。
- 是理解损失函数、参数估计、过拟合和正则化的基础。

## 代码思路

本章代码用同一批数据对比“解析求解”和“迭代优化”：

1. 先生成接近 `y = 3x + 2` 的带噪声样本，模拟真实回归数据不会完全落在直线上。
2. 给 `X` 拼接一列 1 得到 `Xb`，这样偏置 `b` 可以和斜率 `w` 一起放进参数向量 `theta`。
3. `normal_equation` 用矩阵公式一次性求出最小二乘解，作为参考答案。
4. `gradient_descent` 从全 0 参数开始，每一步计算 MSE 梯度并更新 `theta`，同时记录损失变化。
5. 验证部分比较两种方法的结果，说明梯度下降确实能逼近解析解。

## 数学定义

模型：`ŷ = Xw + b`

损失函数（均方误差 MSE）：

```
L(w, b) = (1/n) Σ (yᵢ - ŷᵢ)²
```

## 两种求解方式

### 1. 正规方程（Normal Equation）

直接得到解析解，无需迭代：

```
w* = (XᵀX)⁻¹ Xᵀy
```

- 优点：一步求解，精确
- 缺点：当特征数量 n 很大时，矩阵求逆 O(n³) 代价高

### 2. 梯度下降

迭代更新参数，通用性强，适合大规模数据（详见模块 03）。
