# 模块 06：多层感知器（MLP）

## 核心概念

多层感知器（MLP）是最基础的深度神经网络：多个全连接层堆叠，层间引入非线性激活。

## 实际作用（用途）

- 适合处理表格数据、固定长度特征和简单分类/回归问题，例如信用评分、价格预测或用户流失预测。
- 常作为其他模型中的子模块：Transformer 的 FeedForward 层、推荐系统的特征交互层都可以看作 MLP。
- 可作为快速原型和强基线，用来判断当前特征是否已经包含足够预测信息。
- 在 MNIST 等任务中展示完整训练流程：输入展开、前向传播、损失计算、反向传播和分类评估。

## 代码思路

本章代码实现一个完整的两层分类网络训练闭环：

1. 先构造非线性二维分类数据：两个坐标同号为一类，异号为另一类，单层线性模型难以分开。
2. 参数字典 `params` 保存两层网络的 `W1/b1/W2/b2`，便于前向和反向统一访问。
3. `mlp_forward` 执行 `Linear -> ReLU -> Linear -> Softmax`，返回分类概率和反向传播需要的缓存。
4. `train` 中用交叉熵计算损失，再利用 `softmax + cross entropy` 的简化梯度反向更新所有参数。
5. 训练后计算准确率，并用散点图展示模型学到的非线性分类边界。

## 网络结构

```
输入层 → [隐藏层₁ → 激活] → [隐藏层₂ → 激活] → ... → 输出层
```

每一层的运算：

```
z = Wx + b
a = σ(z)
```

## 通用近似定理

含足够神经元的单隐藏层 MLP 可近似任意连续函数（Cybenko, 1989）。
但实践中，深层网络比宽层网络参数效率更高。

## MNIST 分类

本模块将实现一个 2 层 MLP 对 MNIST 手写数字分类（10 类）。

网络结构：`784 → 128 → 64 → 10`

- 损失函数：交叉熵（Cross-Entropy）
- 输出激活：Softmax

## Softmax

```
softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)
```

将原始分数转换为概率分布，所有类别概率之和为 1。
